ОХЛАЖДЕНИЕ ПРОЦЕССОРА — обновлённая визуализация

Запуск из распакованной папки:
    python -m pip install -r requirements.txt
    python app.py

Нужен Python 3.10+ с tkinter. В Windows tkinter обычно входит в Python;
в Ubuntu/Debian при необходимости установите пакет python3-tk.

Изменены app.py и graphics.py. Модель и расчёт сохранены без изменений.
Если обновляете прежнюю папку проекта, замените в ней эти два файла.

Плавные цветовые карты используют линейную интерполяцию температур.
Положение сечений изменяется непрерывно; их поворот и масштаб сохраняются.
Геометрия изотермических поверхностей кэшируется для каждого расчёта.
Бирюзовый контур обозначает охлаждаемые грани, розовый — площадку нагрева.
Единая температурная шкала используется на обеих вкладках.
Интерполяция служит только для отображения и не повышает точность расчёта.

preview.png — пример графиков с параметрами по умолчанию.
Проверено построение графиков без окна: расчёт по умолчанию, дробные
и крайние положения сечений, однородное температурное поле.
Интерактивное окно tkinter в среде проверки не запускалось.
