# Охлаждение процессора — настольное приложение

Обычное окно Python: браузер, HTTP-сервер, HTML и JavaScript не используются.
Нужен Python 3.10 или новее с Tkinter. На Windows Tkinter обычно включён в установщик Python
(компонент Tcl/Tk). На Ubuntu при необходимости установите пакет python3-tk.

## Запуск в Windows / PowerShell / VS Code

Распакуйте архив полностью. Откройте терминал в папке cpu_cooling_desktop:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

При следующих запусках достаточно последней команды. Интернет нужен только для установки пакетов.
На Linux: python3 -m venv .venv, затем .venv/bin/python вместо .venv\Scripts\python.exe.
Если работаете из обычного окружения с установленными пакетами: python app.py.

## Управление

Слева выберите охлаждаемые стороны кнопками −X, +X, −Y, +Y, +Z.
Голубая кнопка означает включённое охлаждение. Нижняя сторона −Z занята процессором.
Заполните параметры и нажмите «Рассчитать» (или Enter). Поддерживаются десятичные точка и запятая.
Вычисление выполняется в отдельном потоке. На мелкой сетке расчёт может занимать заметное время.
Во время вычисления параметры заблокированы, чтобы результат соответствовал введённым значениям.

Справа две вкладки: «Изотермические поверхности» и «Температурные сечения».
На второй вкладке три ползунка перемещают сечения. Это не запускает повторный расчёт.
Модель вращается левой кнопкой мыши; масштаб меняется колесом.
В заголовке окна после расчёта отображается максимум температуры контакта с процессором.

Каркас — границы куба, голубые контуры — охлаждаемые стороны, красный квадрат — процессор.
Температурное поле задано в центрах ячеек. Изоповерхности интерполируются внутри этой области,
поэтому их края не обязаны совпадать с наружной стенкой. Цветовая шкала общая для обеих вкладок.
Максимальная температура контакта вычисляется отдельно от поля в центрах ячеек.
Вода имеет заданную постоянную температуру; теплообмен с ней описывается коэффициентом alpha.

## Файлы

- thermal_model.py — общий численный модуль из веб-версии: сетка, условия Робина, Якоби, Зейдель, SOR.
- calculation.py — проверка параметров и запуск SOR с проверкой баланса мощности.
- graphics.py — карты температур и изоповерхности Matplotlib / marching cubes.
- app.py — окно Tkinter, обработка параметров, фоновое вычисление и ползунки.

Чтобы использовать те же расчёты в notebook, импортируйте ThermalModel из thermal_model.py.
Настольная версия вызывает тот же модуль, а не отдельную реализацию уравнений.
